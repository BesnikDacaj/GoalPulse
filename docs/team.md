## Coordinator responsibilities

The coordinator is the single point of contact for the instructor, owns the merge button on `main`, schedules weekly stand-ups, and ensures every milestone is delivered on time.

## Communication

- GitHub Issues for tasks
- GitHub Pull Requests for code review (minimum one reviewer)
- Discord channel `#goalpulse` for stand-ups
- Weekly Tuesday 18:00 video call

## Conflict resolution

If two members disagree on an architectural decision, the coordinator decides; if the coordinator is one of the disagreeing parties, a tiebreaker call is taken with a third member. There were no escalations during the Spring 2026 semester.
